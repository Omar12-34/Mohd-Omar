# COVID-19 Exploratory Data Analysis (EDA) in R

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a COVID-19 dataset using the R programming language. The objective is to understand the dataset through statistical summaries, data cleaning, transformation, and various visualizations.

## Dataset

**Dataset Source:**
https://raw.githubusercontent.com/salemprakash/EDA/main/Data/covid-data.csv

The dataset contains COVID-19 information for different countries, including:
- Country
- Continent
- Date
- Total Cases
- New Cases
- Total Deaths
- Population
- Other COVID-related statistics

## Objectives

The project includes:

- Loading the dataset
- Basic statistical analysis
- Handling missing values
- Data cleaning
- Data transformation
- Univariate analysis
- Bivariate analysis
- Multivariate analysis

## Tools and Libraries

- R
- ggplot2
- tidyverse
- corrplot
- GGally

## Visualizations

### Univariate Analysis
- Histogram of Total Cases
- Boxplot of Total Deaths
- Bar Chart of Countries by Continent

### Bivariate Analysis
- Scatter Plot (Total Cases vs Total Deaths)
- Boxplot (New Cases by Continent)
- Bar Chart (Top 10 Countries by Total Cases)

### Multivariate Analysis
- Correlation Matrix
- Scatter Plot Colored by Continent
- Pair Plot (GGally)
